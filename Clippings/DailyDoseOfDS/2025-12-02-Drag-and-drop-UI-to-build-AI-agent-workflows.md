# 用于构建 AI Agent 工作流的可视化拖拽 UI（Drag-and-drop UI to build AI agent workflows.）

Sim 是一款轻量级且用户友好的开源平台，允许开发者在几分钟内构建 AI Agent 工作流。

### 核心特性

* **实时工作流执行**：支持即时预览与调试。
* **无缝集成**：可连接你喜爱的常用工具与服务。
* **本地模型支持**：通过 Ollama 轻松对接本地开源大模型。
* **直观的拖拽 UI**：基于 ReactFlow 打造流畅的可视化编辑体验。
* **多样化部署方案**：提供 NPM、Docker 及 Dev Containers 等多种部署选项。

根据测试体验，相比于 n8n，Sim 在智能化工作流构建上展现出独特的优势：
1. 更为直观的交互界面；
2. 体验更佳的 AI Copilot 助手，加速构建流程；
3. 为智能 Agent 原生设计的 AI Native 工作流架构。
