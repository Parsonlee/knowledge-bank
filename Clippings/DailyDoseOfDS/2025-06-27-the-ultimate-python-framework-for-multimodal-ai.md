# 用于多模态AI的终极Python框架（The ultimate Python framework for multimodal AI）

数据管道占据了AI开发90%的时间。部署它们需要几周的时间，但当需求改变时它们可能会在几分钟内崩溃。

当你的数据是多模态时，情况会变得更糟。

Pixeltable 是一个处理整个多模态管道（图像、视频、音频、文档和结构化数据）的框架，从数据存储到模型执行均可覆盖。

它能在同一个地方无缝管理图像、视频、文本和表格数据。

完全开源。
