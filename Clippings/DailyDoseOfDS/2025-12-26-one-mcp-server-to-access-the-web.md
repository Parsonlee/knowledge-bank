# 一个用于访问网络的 MCP 服务器（One MCP server to access the web.）

当智能体（Agents）使用与网络相关的工具时，它们往往会遇到如 IP 封锁、机器人流量检测、验证码求解等问题：

* 智能体会遭遇频率限制或直接被屏蔽。
* 智能体需要处理包含大量 JavaScript 或受到地理位置限制的网站。

这些问题严重阻碍了智能体的执行效率。

Bright Data MCP 服务器为你提供了 30 多种强大的工具，允许 AI 智能体在不被屏蔽的情况下访问、搜索、抓取网页并与网页进行交互。

与传统的爬虫工具不同，这款 MCP 服务器会根据目标网站的结构，动态选择最有效的工具。

其中一些工具包括：

* 浏览器工具 (Browser tool)
* 网页解锁 API (Web Unlocker API)
* 抓取 API (Scraper API)
* 针对特定平台的抓取工具（如 Instagram、LinkedIn、YouTube 等）
* 搜索引擎结果页面 API (SERP API)，等等。
