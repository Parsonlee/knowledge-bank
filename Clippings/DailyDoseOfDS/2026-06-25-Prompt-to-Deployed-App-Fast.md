# 从 Prompt 到部署：跳过脚手架快速生成 Web 应用

自己动手编写代码固然可行，但关键在于你是否想把整个晚上都耗在接鉴权、搭建前端和配置部署流水线上。

只要在输入框中描述你的应用需求，Bolt.new 就能直接在浏览器中构建完整的全栈应用：包含可用的 UI、后端逻辑以及可直接分享的上线 URL。

你可以快速为最新的数据分析原型化一个仪表盘、搭建内部工具，或者在投入真实工程时间之前验证某个想法。随后你可以完全掌控交付的代码——导出代码、扩展功能并部署到任何地方，无厂商锁定。
