# 为你的 AI 打造的网页浏览器（A web browser for your AI.）

Browserbase 为 AI 智能体和应用程序提供网页浏览能力。

如果您正在构建需要与网站交互、填写表单或模拟用户行为的自动化流程，Browserbase 可以为您管理相关的基础设施，从而让您无需自行维护庞大的无头浏览器（headless browsers）集群。

随着 OpenAI 新推出的 Computer Using Agent API 带来的热潮，Browserbase 构建了这一工具包的开源版本——CUA Browser，供您亲自体验测试。
