# 使用 Factory 将任意论文一键生成完整代码（Generate code for any research paper using Factory!）

许多前沿 AI 研究论文在公开发布时并未开源官方实现代码。Factory 推出的 **Paper2Code** 功能提供了简单高效的两步转化解决方案：

1. **下载论文 PDF**：例如下载 DeepSeek-R1 的官方研究论文。
2. **交付给 Factory Droids**：Factory 内部的智能 Agent（Droids）会自动拆解任务、规划架构方案、编写并测试模块化代码，最终提交生产可用的 Pull Request。
