# 使用 ColiVara 让您的 RAG 应用智能 10 倍（Make your RAG application 10x smarter with ColiVara.）

ColiVara 是一种独特的文档检索方法，它不需要文档分块或文本处理。

它仍然感觉像是 RAG，但没有 OCR、文本提取、表格损坏或图像丢失的问题。

-->ColiVara GitHub 
ColiVara GitHub 

这就是它为何强大的原因：

* 基于视觉的索引
* 支持 100 多种文件格式
* 无缝的本地或云端快速入门
* 最先进的多模态检索
* 适用于 Python/TypeScript 的 API 和 SDK
* 后期交互嵌入 (Late-interaction embeddings) 提供额外的准确性
* 无需管理向量数据库（底层使用 pgVector）
