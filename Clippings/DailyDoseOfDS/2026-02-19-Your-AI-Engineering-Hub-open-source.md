# 开源 AI 工程枢纽（Your AI Engineering Hub [open-source]）

我们在一年前开源了 **AI Engineering Hub** 项目！

今天，该项目在 GitHub 上达成了 **30k Star** 的里程碑！🌟

它包含 90+ 个动手实操项目，涵盖了以下核心技术主题：

* **RAG**（检索增强生成）
* **MCP**（模型上下文协议）
* **AI Agents**（智能体架构）
* **Finetuning**（模型微调）
* **AI Memory**（智能体记忆系统）
* **Eval and Observability**（评估与可观测性）
* **LLMOps / 性能优化**
* 以及更多实战内容……

欢迎查看 GitHub 仓库并加星支持：[AI Engineering Hub GitHub Repo](https://github.com/patchy631/ai-engineering-hub)。
