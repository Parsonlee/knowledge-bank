# 将任意 LLM 连接到任意 MCP 服务端！（Connect any LLM to any MCP server!）

`mcp-use` 是一个开源框架，用于将任意大语言模型（LLM）连接到任意 MCP（Model Context Protocol）服务端，并构建具备工具访问权限的自定义 Agent，无需依赖闭源应用客户端。

它允许你构建 100% 本地运行的 MCP 客户端。

项目仓库：[mcp-use GitHub](https://github.com/mcp-use/mcp-use)。
