# 机器学习中的主动学习

数据标注困难、昂贵且耗时。对于起初没有标注数据的场景，主动学习是一种相对简单、成本较低的监督模型构建方法：让人主动反馈模型难以处理的样本。

## 流程

1. 先人工标注数据集中的极小一部分。邮件作者曾成功地只标注约 1% 的数据，并建议从这一量级开始尝试。
2. 用这小部分已标注数据训练模型。模型一开始不会很好，但这没有关系。
3. 在未标注数据上生成预测。因为没有真实标签，无法直接判断预测是否正确。
4. 使用能显式或隐式提供预测置信度的模型。概率模型很适合，因为可从概率输出得到置信度的代理指标。
5. 按置信度排序全部预测，交给人工标注低置信度的预测，并将其与初始标注集一起反馈给模型。
6. 重复“训练 → 生成预测与置信度 → 标注低置信度预测”的过程，直到性能令人满意。

## 如何理解置信度

可以考察最高概率与第二高概率之间的差距：差距大可能表示模型对预测有信心；差距小则可能表示模型没有信心。没有必要标注模型已经有信心的预测，优先标注低置信度样本能节省时间。

主动学习可显著节省在未标注数据集上构建监督模型的时间。关键注意点是置信度度量：若这一环节做错，之后每一步训练都会受影响。

## 协作学习

将低置信度数据与初始数据合并时，也可以使用高置信度数据，并把模型预测作为它们的标签。邮件将这一主动学习变体称为“协作学习”（cooperative learning）。
