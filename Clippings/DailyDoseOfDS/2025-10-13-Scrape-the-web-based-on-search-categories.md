# 按搜索类别抓取网页

> **广告／推广内容。** 以下为邮件中的 Firecrawl 产品更新，未经独立验证。

邮件称，Firecrawl 的搜索现在可按类别过滤，例如只寻找研究论文或 GitHub 仓库。先以内容类型收窄搜索调用，再抓取结果，可得到更有针对性的内容。

邮件同时列出近期更新：

- “Semantic Crawling” 改善 10 倍；
- 新增由 CoinbaseDev 提供的 x402 Search Endpoint；
- 提供 Fire-enrich v2 示例；
- 改进抓取状态与端点警告等。

- [搜索类别文档](https://docs.firecrawl.dev/features/search#search-categories)
- [Firecrawl Playground](https://www.firecrawl.dev/playground)
