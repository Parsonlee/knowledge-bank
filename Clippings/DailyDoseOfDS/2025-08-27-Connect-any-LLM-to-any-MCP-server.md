# 将任意 LLM 连接到任意 MCP 服务器

[mcp-use](https://github.com/mcp-use/mcp-use) 是一个开源方案，可将任意 LLM 连接到任意 MCP 服务器，并构建能够访问工具的自定义 Agent，而无需使用闭源方案或应用客户端。

它的定位是构建 **100% 本地的 MCP 客户端**。项目源码见 [GitHub 仓库](https://github.com/mcp-use/mcp-use)。
