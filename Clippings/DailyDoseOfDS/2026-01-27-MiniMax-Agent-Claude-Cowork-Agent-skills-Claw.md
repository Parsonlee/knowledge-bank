# MiniMax Agent：集 Claude Cowork、Agent Skills 与 Clawdbot 于一体的桌面智能体（MiniMax Agent = Claude Cowork + Agent skills + Clawdbot）

MiniMax 刚刚推出了 **Agent Desktop（桌面端环境）**，为 AI Agent 提供了一个能够在用户本地系统中真正执行自主工作的桌面环境。

它不仅打破了传统聊天界面的局限，还能代表用户在本地与云端跨系统执行复杂任务：

### 核心功能与亮点：

* **自主网页浏览与信息收集**：在浏览器中自主搜索、爬取与整理数据。
* **多系统连接与协同**：直接无缝连接电子邮箱、日历、GitLab 代码仓库以及运维监控系统。
* **开发者任务自动化**：自动化读取代码、提交 Merge Request（MR）以及处理系统报警。
* **专家系统（Experts）与自定义工作流**：支持运行预置的领域专家 Agent，或针对特定业务流程构建自定义 Agent。

MiniMax 旗下模型在各类 Agent 基准测试中一直表现优异，而 Agent Desktop 进一步展示了其强大的落地能力。新注册账户还将获得 1000 免费积分供测试体验。
