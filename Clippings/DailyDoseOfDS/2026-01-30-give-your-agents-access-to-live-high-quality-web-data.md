# 为你的 Agent 提供实时高质量网络数据（Give your Agents access to live, high-quality web data!）

Firecrawl 刚刚发布了面向 Agent 的 Firecrawl Skill + CLI 工具。

像 Claude Code、Codex 和 OpenCode 这样的 AI 代理需要来自网络的实时高质量上下文数据。

该 CLI 工具能够通过基于 bash 的搜索，将网络内容提取为本地文件，从而实现最高的 Token 效率。

你所需要做的仅仅是进入终端并运行：
`$ npx skills add firecrawl/cli`
