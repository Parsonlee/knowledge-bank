Bolt.new：从 Prompt 一键直接生成并部署 Full-stack Web 应用
在以往构建 AI 原型时，开发者往往需要花费大量时间手动搭建 Auth 认证、前端 UI 以及 CI/CD 部署流水线。


Bolt.new 允许开发者直接在浏览器输入框中用自然语言描述应用需求，系统将自动生成具备完整 UI、后端逻辑与数据库的 Full-stack 全栈应用，并即时提供可访问的在线 URL。代码支持一键导出且无平台锁定。
