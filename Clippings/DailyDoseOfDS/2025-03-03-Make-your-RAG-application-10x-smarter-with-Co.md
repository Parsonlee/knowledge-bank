# 用 ColiVara 让你的 RAG 应用更智能

> [!warning] 广告 / 赞助内容
> 本文是 ColiVara 的推广内容；标题中的“10 倍”是邮件宣传语。

[ColiVara](https://github.com/tjmlabs/ColiVara) 是一种不需要分块或文本处理的文档检索方法。邮件称，它仍有 RAG 的使用感受，但无需 OCR、文本提取，也不会出现损坏表格或遗漏图片的问题。

邮件列出的特点包括：

- 基于视觉的索引；
- 支持 100 多种文件格式；
- 可快速在本地或云端启动；
- 最先进的多模态检索；
- 同时提供 Python 与 TypeScript 的 API 和 SDK；
- 使用后期交互嵌入以提高准确性；
- 无需管理向量数据库，底层使用 pgVector。

项目地址：[ColiVara GitHub](https://github.com/tjmlabs/ColiVara)。
