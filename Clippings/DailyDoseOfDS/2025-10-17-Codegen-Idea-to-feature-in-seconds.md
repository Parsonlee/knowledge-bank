# Codegen：几秒内把想法变成功能

> **广告／推广内容。** 以下为邮件中的产品介绍，未经独立验证。

[Codegen](https://codegen.sh/join) 的定位是：用自然语言描述任何代码改动，再由 AI 执行实现工作。邮件称其已集成到 Slack，因此可以不离开聊天窗口便完成 PR 审阅、发布功能和启动新项目。

示例中，作者要求它使用 Gemini API 构建一个视频 RAG；Codegen 返回了一个 PR，并由此产出可运行结果。该产品称连接 GitHub 账号后可免费使用。

- 产品入口：[Build with Codegen Agents](https://codegen.sh/join)
