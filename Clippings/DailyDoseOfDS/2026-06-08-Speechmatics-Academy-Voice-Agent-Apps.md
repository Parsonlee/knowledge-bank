# 构建生产级语音 Agent 应用的开源代码库：Speechmatics Academy

语音 Agent 需求巨大，但高质量的完整实战范例极少。Speechmatics Academy 开源了一系列开箱即用的运行示例，涵盖批处理、实时语音、TTS 等方向：

丰富技术栈集成：包含 LiveKit、Pipecat、Twilio 和 VAPI 的完整闭环，覆盖 WebRTC 捕获、轮到检测（Turn detection）、说话人聚焦、打断处理与 Function Calling。

生产级应用场景：包含 SRT 字幕生成、呼叫中心主题检测，以及结合 Silero VAD 分块的符合 HIPAA 规范的医疗微批处理。
