# 稀疏注意力 (Sparse Attention)

## 物理定位：打破二次方计算瓶颈
在传统的 Transformer 架构中，全向自注意力（Full Self-Attention）要求计算序列中任意两个 Token 之间的关联性。对于长度为 $N$ 的输入序列，注意力矩阵的尺寸为 $N \times N$，其计算复杂度和显存占用呈二次方级（$O(N^2)$）增长。这导致大语言模型（LLM）在处理数十万乃至百万字级别的超长上下文时遇到了极大的物理算力与显存瓶颈。

**稀疏注意力（Sparse Attention）**的物理定位是一种**近似注意力计算方法**。它的核心策略是不计算所有 Token 对之间的注意力分数，而是通过规则或自适应方式限制只计算子集 Token 之间的注意力，将注意力矩阵“稀疏化”，从而大幅度降低计算复杂度与内存开销，使超长序列的计算在物理上变得切实可行。

---

## 核心实现模式

稀疏注意力主要分为两大类设计模式：

### 1. 局部窗口注意力 (Local / Sliding Window Attention)
- **机制原理**：规定每个 Token 仅能关注其周围固定大小的局部窗口（Local Window）内的邻近 Token，而忽略距离较远的 Token。
- **计算复杂度**：通过限制窗口大小 $W$，将复杂度从 $O(N^2)$ 降低到线性的 $O(N \times W)$。
- **典型应用**：
  - 例如 **ModernBERT** 采用的局部注意力窗口配置（如 128 local window）。每个 Token 在计算注意力时仅与前后 128 个位置的 Token 交互。
  - 通过在多层 Transformer 中堆叠局部窗口，深层网络依然可以通过“感受野（Receptive Field）”的层层扩大来变相获取长距离的全局上下文信息。

### 2. 自适应学习注意力 (Learning-based / Adaptive Sparse Attention)
- **机制原理**：不再依靠人工设计的固定规则（如滑动窗口），而是**让模型自主学习并选择**应当关注的高价值 Token。
- **工作机制**：在模型运行或训练过程中，通过特定的可学习路由机制（Routing）或注意力分数的预测模型，筛选出那些距离虽远但对于语义表达至关重要的关键 Token，对其进行针对性注意力计算。
- **优势与权衡**：这种模式在降低计算开销的同时，比静态的局部窗口保留了更丰富的远距离依赖信息。但其引入了动态的路由决策，可能会带来额外的系统开销与实现复杂度。

---

## 稀疏注意力的主要权衡
虽然稀疏注意力极大地缩减了运算量，但它毕竟是一种对全局信息的“近似截断”。其设计面临以下折中：
- **性能 vs. 复杂度**：稀疏度越高，运算越快，但信息丢失可能越多，可能导致模型对长距离上下文的召回能力（如 Needle In A Haystack 任务）有所下降。
- **硬件友好度**：在 GPU 等并行计算设备上，不规则的稀疏矩阵乘法（Sparse Matrix Multiplication）往往难以达到理论上的硬件加速效果，容易导致内存对齐和计算核心闲置问题。因此在工程实现上，往往需要精心设计分块稀疏（Block-Sparse）等硬件友好的计算方式。
