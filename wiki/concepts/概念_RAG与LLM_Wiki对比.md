# 概念：RAG 与 LLM Wiki 对比

## 定义与核心差异

**RAG（检索增强生成）** 与 **LLM Wiki（大模型维基范式）** 是当前 AI 知识管理与应用的两大技术路线，二者非简单的取代关系，而是适用场景与本质思维的不同。

| 对比维度 | RAG（检索增强生成） | LLM Wiki（大模型维基） |
|---|---|---|
| **核心适用场景** | 几万份合同、几千份技术文档的**大规模精确检索** | 持续阅读学习、记笔记、概念沉淀与**个人/团队知识积累** |
| **工作发生时机** | **查询时（Query-time）**：临时切块检索、现场拼凑回答 | **摄入时（Ingestion-time）**：预先结构化拆解、编译与链接 |
| **知识复利效应** | **零积累**：每次查询从零开始，搜完即散 | **高复利**：新素材自动关联既有概念，网络越密价值越大 |
| **存储与依赖** | 依赖外部向量数据库与 Embedding 服务（基建成本高） | 仅需本地文件夹与 Markdown 纯文本（零基建依赖） |
| **底层思维方式** | 被动检索：“我有一堆文档，AI 帮我搜” | 主动编译：“AI 帮我整理与链接知识，我随时看” |
