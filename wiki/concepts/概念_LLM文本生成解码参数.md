# LLM 文本生成解码参数

在自回归大型语言模型（LLM）中，模型最终的输出是一个高维 Logits 向量，对应词表（Vocabulary）中每个词的未归一化得分。为了将 Logits 转化为最终生成的文本，通常需要应用解码策略。
本概念页详细解构决定 LLM 生成行为的 7 个核心解码参数。

## 1. Max Tokens (最大生成长度限制)
- **定义**：限制单次生成响应的最大 Token 数量硬性上限。
- **作用机制**：当模型生成的 Token 数量达到该设定值时，无论是否生成了终止符（如 `<|endoftext|>` 或 `<|im_end|>`），解码流程都会被强制掐断。
- **调优策略**：
  - 设置过小会导致输出截断、信息不完整。
  - 设置过大（且无有效停止序列）可能导致模型在生成无效或重复文本时浪费大量计算资源。

## 2. Temperature (温度)
- **定义**：控制生成文本随机性与创造性的缩放因子。
- **数学逻辑**：
  假设词表中第 $i$ 个 Token 的 Raw Logit 为 $z_i$，在 Softmax 归一化概率计算中加入温度参数 $T > 0$：
  $$P(\text{token}_i) = \frac{\exp(z_i / T)}{\sum_j \exp(z_j / T)}$$
  - **当 $T \to 0$ (低温)**：Logits 之间的差异被无限放大。Softmax 输出概率分布趋向于 One-hot 分布（即概率最高的 Token 接近 1.0，其他接近 0.0）。此时模型处于**确定性解码（贪婪搜索 Greedy Search）**，输出单一、稳定，但缺乏多样性。
  - **当 $T \to 1.0$ (默认或中温)**：保持原始模型的 Logits 差异，模型根据其预训练分布概率进行采样。
  - **当 $T > 1.0$ (高温)**：使得 $z_i / T$ 之间的数值差异变小，Softmax 后的概率分布更加平滑，**信息熵（Entropy）显著增大**。每个 Token 的概率更加均匀，高概率词的优势被削弱，低概率的冷门词被采样的几率增加，使得文本极具创意和随机性，但也伴随着幻觉和乱码（Noise）风险。

## 3. Top-k (前 k 截断采样)
- **定义**：将下一次预测 Token 的采样候选池限制为概率最高的前 $k$ 个 Token。
- **作用机制**：
  - 在计算完所有词的概率后，对概率进行降序排列，仅保留前 $k$ 个词，将其余词的概率清零，并在保留的 $k$ 个词中进行重新归一化采样。
  - **例如 $k=5$**：模型只在最可能的前 5 个选项中摇号，完全排除其他冷门选项。
- **调优策略**：
  - **优点**：能够有效防止模型在长尾分布中采到语义完全不通的词。
  - **缺点**：$k$ 设得太小会导致文本生成单一、刻板甚至陷入无限死循环（如不断重复某几句话）。

## 4. Top-p / Nucleus Sampling (核采样)
- **定义**：动态截断机制，限制采样候选池为累计概率达到阈值 $p$ 的最小 Token 集合。
- **作用机制**：
  - 将所有词按概率降序排列，从概率最大的词开始累加概率，直到累加和 $\sum P \ge p$ 时的临界位置。
  - 只有这个累加子集（即“核”，Nucleus）中的 Token 会被保留用于采样，其余清零并重新归一化。
  - **自适应性**：相较于 Top-k 固定的候选数量，Top-p 是自适应的。
    - 当概率分布非常集中（模型非常笃定下一个词是什么），“核”内的 Token 数量会很少（可能只有 1-2 个）。
    - 当概率分布非常平缓（模型不确定下一个词是什么），“核”内的 Token 数量会动态增加（可能包含几十个词）。

## 5. Frequency Penalty (词频惩罚)
- **定义**：根据词在当前已生成文本中出现的**绝对频次**来减少其再次被生成的概率。
- **作用机制**：
  对第 $i$ 个 Token 的 Logit $z_i$ 施加惩罚：
  $$z'_i = z_i - (\text{Frequency Penalty}) \times c_i$$
  其中 $c_i$ 是该 Token 在已生成的 Prompt 和 Completion 中出现的总次数。
  - 正值（大于 0）：随着该词出现次数的累加，其 Logit 被惩罚得越来越低，极大程度地压制了重复性词汇或短语。
  - 负值（小于 0）：会鼓励模型不断重复已生成的词。

## 6. Presence Penalty (存在惩罚)
- **定义**：只要一个词在当前已生成的文本中**出现过**，就对其施加一次性的固定惩罚，而不考虑出现的具体频次。
- **作用机制**：
  对第 $i$ 个 Token 的 Logit $z_i$ 施加惩罚：
  $$z'_i = z_i - (\text{Presence Penalty}) \times \mathbb{I}(c_i > 0)$$
  其中 $\mathbb{I}(c_i > 0)$ 是指示函数（只要出现过就是 1，否则为 0）。
  - **目的**：通过对已产生的概念进行单一惩罚，驱使模型放弃已知的话题和用词，转向未被提及的新词汇、新概念，从而提升回答的主题多样性和发散性。

## 7. Stop Sequences (停止符序列)
- **定义**：由用户自定义的一组字符串/Token 序列。
- **作用机制**：
  - 在自回归生成过程中，每生成一个 Token，模型会检测最近生成的文本片段是否匹配这些自定义的停止符。
  - 一旦匹配成功，解码过程立即安全挂起。
- **典型场景**：
  - 在代码生成中设置停止符为 `\n\n` 或 `def `，防止模型无休止地往下写其他无关函数。
  - 在结构化输出（如 JSON）中，通过设置 `}` 为停止符或配合特定边界字符，强行截断可能溢出的额外描述，确保下游 Parser 不会报错。
