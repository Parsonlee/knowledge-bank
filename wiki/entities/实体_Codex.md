# 实体：Codex

## 简介

**Codex** 是由 OpenAI 推出的代码生成模型与编码智能体系统（包括早期 Codex 模型及后续在 ChatGPT/API 中的编码 Agent 实现）。

## 在 Harness 工程中的定位

在 [[concepts/概念_Harness_Engineering|Harness Engineering]] 中，Codex 与 [[entities/实体_Claude_Code|Claude Code]] 被作为同一模型基座配合不同 Harness 产生天差地别产品力的典范代表。
