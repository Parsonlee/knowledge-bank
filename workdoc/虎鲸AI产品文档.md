# 1.产品介绍

虎鲸AI是壹药网数据产品和算法团队基于Dify平台结合LLM及Agent的方式实现的ChatBI智能分析平台。虎鲸AI智能数据分析平台可以为用户提供更加灵活方便的数据分析形式，普通业务用户无需学习复杂的敏捷BI的工具使用，数据分析师也无需编写SQL，通过自然语言即可实现和大数据平台数据进行交互，完成数据的提取和分析。

举例：

+:--------:+:------------:+:--------:+:--------:+:--------:+:-------------------:+
| **指标** | **业务模式** | **基期** | **本期** | **ΔX_i** | **贡献度**          |
|          |              |          |          |          |                     |
|          |              |          |          |          | **（ΔX_i/Δ_整体）** |
+----------+--------------+----------+----------+----------+---------------------+
| GMV      | 自营备货     | 500      | 800      | 300      | 300/600=50%         |
|          +--------------+----------+----------+----------+---------------------+
|          | 自营JBP      | 400      | 600      | 200      | 200/600=33.33%      |
|          +--------------+----------+----------+----------+---------------------+
|          | MP           | 300      | 400      | 100      | 100/600=16.66%      |
|          +--------------+----------+----------+----------+---------------------+
|          | **整体**     | **1200** | **1800** | **600**  | **100%**            |
+----------+--------------+----------+----------+----------+---------------------+

##### 实现方案

业务提交示例：

1、本周营销品GM%下滑，请问是哪个品出现了异常或者哪个品类出现了异常

2、本周营销品活跃客、GMV、动销sku均下滑，请问同比药城整体情况，或者市场情况，是否是正常波动

3、本月某个产品编码品GMV下滑较大，请问是整个品类（主码）都在下滑，还是这个品类中的这个品牌在下滑，还是单纯这个编码所在的产品出现价格或其他异常导致下滑

4、本月JBP业务GM对比上月同期下滑，引起的原因示例：百亿补贴参与多、特价活动提报比例高、活动设置失误等

5、核心关注GM的波动，对应引发的原因，根据业务类型不同，需分析的指标不同。

6.  本月部门GAAP对比上月同期下降15%，什么原因？

**分析方法：**

**step1: 获取数据**

本期（本月）：

过滤条件：日期区间=本月，客户类型=批发企业

字段选择：收货城市、采购商名称、GMV、日期

基期（上月同期）：

过滤条件：时间范围=上月同期，客户类型=批发企业

字段选择：收货城市、采购商名称、GMV、日期

**时间周期说明：**

**1、环比：表示连续2个统计周期（比如连续两月）内的量的变化比**

举例：

1.1 本月环比：本月VS上月同期

必须是同一个时间周期，即9月环比8月同期，如今天为9月26日，则本月为9月1日-9月25日，环比8月则为8月1日-8月25日

如问题月份为完整月则取对应完整月日期（今天为1号，则完整月为上月环比上上月）

1.2 本周环比: 本周VS上周同期

必须是同一个时间周期，即本周环比上周同期，如今天为周四，则本周为周一-周三，环比上周同期则为上周一-上周三

如问题本周为完整周则取对应完整周日期（今天为周一，则完整周为上周环比上上周）

1.3 昨日环比、本季环比、今年环比同理，环比上个周期

**2、同比：一般情况下是本年第n月与过去某年的第n月比**

2.1 本月同比：本月VS去年同月同期

必须是同一个时间周期，即今年9月同比去年9月同期，如今天为9月26日，则本月为9月1日-9月25日，同比去年9月则为23年9月1日-9月25日

#### 2、除法指标（用于计算GAAP毛利率）

##### 实现方案

贡献度计算使用双因素法，即**贡献度=波动贡献+结构贡献**

![descript](media/image21.png){width="3.84375in"
height="1.8229166666666667in"}

维度项i的贡献度 =

(本期维度项i的指标值 - 基期维度项i的指标值) \*
基期维度项i的分母值占比基期总分母值

\+ (本期维度项i的分母值占比本期总分母值 -
基期维度项i的分母值占比基期总分母值) \* (本期维度项i的指标值 -
基期总指标值)

**再进行归一化处理得出每个维度项i的百分比贡献度**

举例：

GAAP毛利率 = GAAP毛利额 ÷ Revenue

本期总GAAP毛利额率 = 本期总GAAP毛利额 ÷ 本期总Revenue

分析维度：合并中分类

包含维度项：五官科、神经系统类、糖尿病类\...\.....等

五官科的贡献度 = (本期五官科GAAP毛利率 - 基期五官科GAAP毛利率) \*
(基期五官科Revenue ÷ 基期总Revenue)

\+ (本期五官科Revenue ÷本期总Revenue - 基期五官科Revenue ÷
基期总Revenue) \* (本期五官科GAAP毛利率 - 基期总GAAP毛利率)

**注：如分析的某个维度项中分项如果在本期或则基期未产生数值，则将其没有数值的当期分子分母设置为1，指标值等于总的指标值，其余计算不影响。**

**2、除法指标（用于计算GAAP毛利率(去税) = GAAP毛利额÷Revenue、ARPU =
Revenue÷顾客数、ARPO = Revenue÷订单数）**

举例：

+:--------:+:--------------------:+:--------:+:--------:+:------------------:+:--------------------------:+
|          | **指标**             | **基期** | **本期** | **Δln(本期/基期)** | **贡献度**                 |
|          |                      |          |          |                    |                            |
|          |                      |          |          |                    | **（ΔX_i/Δ_all）**         |
+----------+----------------------+----------+----------+--------------------+----------------------------+
| 分子     | GAAP毛利额(去税)     | 25       | 24       | ln(24/25)          | ln(24/25)/ln(0.04/0.05)    |
|          |                      |          |          |                    |                            |
|          |                      |          |          |                    | =18.29%                    |
+----------+----------------------+----------+----------+--------------------+----------------------------+
| 分母     | Revenue              | 500      | 600      | -ln(600/500)       | -ln(600/500)/ln(0.04/0.05) |
|          |                      |          |          |                    |                            |
|          |                      |          |          |                    | =81.71%                    |
+----------+----------------------+----------+----------+--------------------+----------------------------+
| **结果** | **GAAP毛利率(去税)** | **0.05** | **0.04** | **ln(0.04/0.05)**  | **100%**                   |
+----------+----------------------+----------+----------+--------------------+----------------------------+

计算公式：

解释：从整体看分母和分子分别带来的影响程度。GAAP毛利率本期4%对比基期5%下降1%，GAAP毛利率=GAAP毛利额÷Revenue，分别计算GAAP毛利额和Revenue。

GAAP毛利率(基期) = 25/500 = 0.05

GAAP毛利率(本期) = 24/600 = 0.04

**Δ = -0.01**

Revenue不变，GAAP毛利额变化带来的影响 = 1/500

Revenue变化，GAAP毛利额不变带来的影响 = 24\*(1/600-1/500)

GAAP毛利率(本期) - GAAP毛利率(基期) = 24\*(1/600-1/500) - 1/500 = -0.01
